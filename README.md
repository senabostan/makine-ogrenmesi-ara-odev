# Makine Öğrenmesi Ara Ödev – Müşteri Ayrılma (Churn) Tahmini

## Projenin Amacı
Bu çalışmada, temel bir makine öğrenmesi sınıflandırma akışı küçük ve anlaşılır bir müşteri ayrılma (churn) senaryosu üzerinde uygulanmıştır. Çalışma kapsamında; sentetik veri üretimi, eksik değer temizleme, öznitelik üretimi (feature engineering), kategorik verilerin dönüştürülmesi, ölçekleme, verinin train-validation-test olarak bölünmesi, model eğitimi ve sınıflandırma metrikleriyle performans değerlendirme adımları pratik edilmiştir.

## Kullanılan Teknolojiler ve Kütüphaneler
* Python 3.x
* Pandas
* NumPy
* Scikit-Learn
